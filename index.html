Selected work

Final-year thesis: modelling and verifying an extreme-rainfall event

BSc Physics, University of Alicante, 2025–2026

I simulated, with the WRF weather model, the September 2019 cut-off low (DANA) that hit the Vega Baja del Segura in Alicante and the Campo de Cartagena in Murcia. The WRF mesoscale model ran on nested 9 km and 3 km domains forced by ERA5, and a sensitivity experiment compared high-resolution (5 km) sea-surface temperature with the standard data.

I built the verification system in Python (xarray, wrf-python, NumPy, Matplotlib) and tested it against AEMET stations and the ROCIO grid with Bias, MAE, RMSE, POD, FAR, CSI, TSS, Pearson correlation, the SAL spatial method and paired t-tests.

The high-resolution configuration reduced the MAE by up to 13.5% (p < 0.001).

Data analysis at AEMET

Curricular internship, 150 hours, Alicante observatory, February to May 2026

Four pieces of work with the Spanish State Meteorological Agency, written up for non-technical readers. This chart comes from the first one.

  • Climate trends in Alicante, 1951–2020. Python analysis (pandas, NumPy, Matplotlib) of gridded data in five 30-year periods. The maximum temperature rose by more than 0.5 °C, the minimum by more than 0.7 °C, and rain became less frequent but more intense. Report Code Charts
  • Warming in three settings. A comparison of an urban coastal site, a coastal airport and inland Albacete, with recommendations on heat islands, water management and heat-wave alerts. Report Code
  • Forecast verification exercises. Deterministic and probabilistic verification (Bias, RMSE, MAE, ACC, POD, FAR, CSI, Brier Score, reliability diagrams) using data from AEMET training courses, where I found a warm bias in airport temperature forecasts. Exercises
  • Supercomputing and model data. I set up OpenIFS on the ECMWF HPC cluster (Linux), turned EC-Earth4 output (NetCDF and GRIB) into global seasonal maps in Jupyter, and visualised NASA satellite data.
